# 06: Manage Groups in edit mode

**What to build:** In edit mode a User can add a Group, rename a Group inline, and switch a Group between tiles and compact. The first Group never shows a label on the normal page, even if named.

**Blocked by:** 02

**Status:** resolved

- [ ] "Add group" creates an empty Group that appears at the end
- [ ] Group names are editable inline in edit mode
- [ ] A per-Group control switches between tiles and compact and the normal page reflects it
- [ ] Create-Group and update-Group (name, style) endpoints are in the OpenAPI spec with integration tests, including per-User isolation
