# 08: Settings drawer shell

**What to build:** In edit mode a Settings drawer docks on the left and pushes the page over, so the page stays visible. It shows a placeholder Settings view and stays put while App modals open and close. The real Settings contents (weather key, appearance) come from later specs.

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] The drawer appears on entering edit mode and disappears on Done
- [ ] The page content is pushed over, not covered
- [ ] Opening, saving or cancelling an App modal leaves the drawer unchanged
- [ ] The Edit/Done button stays reachable and does not overlap drawer content
